## 2. ทดสอบแบบผู้ใช้ (manual) และจำนวนแตะ

| งาน | ก่อน | หลัง |
| --- | --- | --- |
| ขาย 1 รายการเงินสด | 5 แตะ (เพิ่ม → เลือก Lot ทั้งที่มี Lot เดียว → ตะกร้าเด้ง → รับชำระ → ยืนยัน) | **3 แตะ** (เพิ่ม → ชำระเงินจากแถบล่าง → ยืนยัน) |
| เพิ่มสินค้าชิ้นถัดไป | 3 แตะ (ปิดตะกร้าที่เด้ง → เพิ่ม → เลือก Lot) | **1 แตะ** |
| เปลี่ยนวิธีชำระ | 2 แตะ (dropdown) | **1 แตะ** (ปุ่มเลือก) |
| รับเงินสดไม่พอดี | พิมพ์ตัวเลข | แตะปุ่ม พอดี / ปัดขึ้น 100 / 500 / 1000 |
| ค้นหาสมาชิก | แตะช่องค้นหาอีกครั้งก่อนพิมพ์ | คีย์บอร์ดขึ้นทันที |
| เลือกสมาชิก / พักบิล | ตะกร้าปิดเองหลังเลือก ต้องเปิดใหม่ | ตะกร้าอยู่ต่อ |

### บั๊กที่เจอระหว่างทดสอบและแก้แล้ว

1. **ตะกร้าปิดเองเมื่อเปิดหน้าเลือกสมาชิกหรือพักบิล** บนจอเล็ก (dialog ซ้อนถูกนับเป็นการแตะนอกตะกร้า)
2. **"ใช้แต้มทั้งหมด" ใช้แต้มเกินมูลค่าบิล** แล้วจ่ายไม่ได้ ตอนนี้หยุดที่มูลค่าบิล
3. **แต้มลดบิลจนเหลือ 0 บาท**: หน้าคำนวณยอมให้ แต่ตอนชำระระบบปฏิเสธ บิลค้างจ่ายไม่ได้ ตอนนี้แต้มต้องน้อยกว่ายอดก่อนภาษีเสมอ (แจ้งตั้งแต่ตอนคำนวณ)
4. **ช่องค้นหาลูกค้าถูกบีบเหลือแต่ไอคอน** ในหน้าลูกค้าและสมาชิก
5. **รูปสินค้าที่โหลดไม่ได้ขึ้นเป็นกรอบรูปแตก** ในหน้าสต๊อกและคลังรูป ตอนนี้แสดงรูปแทน
6. หน้าสต๊อก: แตะสินค้าแล้วรายละเอียดอยู่ใต้รายการ มองไม่เห็นว่าเกิดอะไร ตอนนี้เลื่อนไปที่รายละเอียดให้
7. Superadmin เปิดเมนูใบขาย ต้องกดลิงก์อีกครั้งถึงจะเข้า V2 ตอนนี้เข้าตรง

### ปรับหน้าจอมือถือ

- ประวัติการขาย, การตั้งค่า (สาขา/ผู้ใช้), ใบเบิก, เคลม, สต๊อก, ประวัติซื้อ/แต้มของสมาชิก, หน่วยขายและราคาส่ง: เปลี่ยนจากตารางเลื่อนข้างเป็นการ์ด
- ประวัติการขาย: ช่องค้นหา + ปุ่ม "ตัวกรอง (จำนวน)" แทนช่องกรอง 7 ช่องที่ขวางก่อนเห็นบิล
- สรุปยอดขาย: ตัวเลขขึ้นก่อน เป็นรูปแบบเงินบาท และมีปุ่ม วันนี้ / 7 วันล่าสุด / เดือนนี้
- โปรโมชั่น: รายการขึ้นก่อน ฟอร์มสร้างเปิดเมื่อกด "สร้างโปรโมชั่นใหม่"
- ปุ่ม "+" ในตั้งค่ามีข้อความ "เพิ่มสาขา" / "เพิ่มผู้ใช้"
- การ์ดสินค้าในหน้าขายกะทัดรัดขึ้น จอเดียวเห็นสินค้ามากขึ้นเกือบเท่าตัว
