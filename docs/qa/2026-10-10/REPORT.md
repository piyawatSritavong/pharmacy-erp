## 1. หลายสาขาขายพร้อมกัน แล้วตรวจย้อนว่าเงินและรายงานตรง

สคริปต์ให้ POS ทั้ง 5 สาขา (MES, PHH, PHS, NPT, KNP) ขายพร้อมกันสาขาละ 3 thread ระหว่างนั้นสำนักงานใหญ่ก็ขายแทนสาขา รับชำระหนี้ และโอนสินค้า MES → PHH ตะกร้าสุ่มทั้งหน่วยชิ้น/แพ็ค สมาชิก ใช้แต้ม ขายเชื่อ ส่วนลดท้ายบิล และวิธีจ่ายเงินสด/โอน/ผสม

**การแข่งกันที่เจาะจุดเสี่ยง (ผ่านทั้งหมด):**

- 5 เครื่องแย่ง lot ที่เหลือ 2 ชิ้น → ขายได้ 2 บิลพอดี lot เหลือ 0 ส่วนที่เหลือได้ 409
- สมาชิกคนเดียวใช้แต้มพร้อมกันที่ 5 สาขา (แต้มพอใช้ครั้งเดียว) → สำเร็จ 1 ครั้ง ยอดแต้มตรงกับ ledger
- 6 เครื่องขายเชื่อบัญชีเดียวที่วงเงินพอ 2 บิล → สำเร็จ 2 บิล ยอดค้างไม่เกินวงเงิน
- กดรับชำระตะกร้ารีโมต 4 ครั้งพร้อมกัน → เกิดบิลเดียว
- 2 สาขารับชำระหนี้ก้อนเดียวกันพร้อมกัน → เก็บได้ครั้งเดียว

**กระทบยอด (ผ่านทั้งหมด):**

- บิลที่เครื่องได้รับแจ้ง = บิลในฐานข้อมูล ทั้งจำนวนและยอด แยกรายสาขา
- ทุกบิล: ผลรวมรายการ = ยอดก่อนภาษี, ยอดก่อนภาษี + VAT = ยอดรวม, ยอดชำระตรงกับสถานะการชำระ
- เงินเข้า (เงินสด + โอน) = ยอดที่ POS รับ + หนี้ที่เก็บได้
- "สรุปยอดขาย" ของทุกสาขา = ฐานข้อมูล (ยอดขาย, จำนวนบิล, เงินสด, เงินโอน, ขายเชื่อค้างรับ)
- Export Excel = หน้าจอ, PDF เปิดได้
- ยอดรวมสำนักงานใหญ่ = ผลรวมทุกสาขา = ฐานข้อมูล
- แดชบอร์ด superadmin: ทุกกลุ่มรวมกันเท่ากับยอดบิลของวัน · แดชบอร์ด admin.central: เงินเข้า + ขายเชื่อค้างรับ = ยอดบิลของวัน
- รายงานภาษีรายสาขา = ฐานข้อมูล
- สต๊อกคงเหลือ = ผลรวมคงเหลือของ lot ทุกสาขาทุกสินค้า, ไม่มีสต๊อกติดลบ, ส่วนต่างสต๊อกตั้งแต่เริ่ม = ผลรวม movement, จำนวนบนบิล = movement ขาย
- แต้มคงเหลือ = ledger ทุกคน, แต้มที่ได้ = ปัดลงของ (ยอด ÷ 25), ทุกการใช้แต้มอยู่ใน ledger
- ไม่มีลูกค้าค้างเกินวงเงิน, หน้าลูกหนี้ = ฐานข้อมูล, อายุหนี้รวมได้เท่ายอดค้าง
- เลขที่บิลของวันไม่ซ้ำและไม่ขาดช่วงในทุกสาขา

**บั๊กที่การทดสอบนี้เจอและแก้แล้ว:**

1. โปรของแถมท้ายบิลทำให้**ทั้งบิลขายไม่ได้**เมื่อของแถมในสาขาหมด → แถมเท่าที่มีและแจ้งที่ตะกร้า
2. แดชบอร์ดของ admin.central ไม่แสดงยอดขายเชื่อที่ยังไม่ได้รับเงินเลย → เพิ่มช่อง "ขายเชื่อ ค้างรับ"

วิธีรันซ้ำ (ฐานทดสอบเท่านั้น):

```bash
PYTHONPATH=scripts/qa python3 scripts/qa/multi_branch_reconcile.py --sales 30 --threads 3
```

ผลละเอียดถูกเขียนไว้ที่ `scripts/qa/multi_branch_report.json` (ไฟล์นี้ไม่ได้ commit)
