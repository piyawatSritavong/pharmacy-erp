# บท Demo ลูกค้า · PharmaPOS หลายสาขา

ใช้เวลาประมาณ 25–30 นาที เล่าเรื่องเดียวต่อเนื่อง: **หลายสาขาขายพร้อมกัน แล้วสำนักงานใหญ่เห็นตัวเลขที่ตรงกันทันที** ฟีเจอร์เสริมแทรกอยู่ในเรื่อง ไม่ได้แยกโชว์ทีละเมนู

หลักฐานว่าตัวเลขตรงอยู่ใน [รายงาน QA 2026-10-10](qa/2026-10-10/REPORT.md) และรายละเอียดฟีเจอร์อยู่ใน [ส่วนขยาย V1](versions/V1_EXTENSIONS_2026-10-10.md)

## 1. เตรียมระบบ (ทำก่อนวัน demo)

ใช้ฐานข้อมูลสำหรับ demo โดยเฉพาะ **ห้ามใช้ production**

```bash
docker compose -p pharmacy-erp -f deploy/docker-compose.yml up -d --build
```

จากนั้นเติมข้อมูล demo: โอนสต๊อกตั้งต้นจากโกดังไปคณาเภสัช, หน่วยขายแบบแพ็ค 10, ราคาส่ง, สมาชิก 20 คน, บัญชีขายส่ง 3 ราย และโปรโมชั่น 3 แบบ

```bash
ERP_BASE=http://localhost:8080/api/v1 DATABASE_URL='postgres://pharmacy:pharmacy@localhost:5432/pharmacy_erp?sslmode=disable' PYTHONPATH=scripts/qa python3 scripts/demo/seed_demo_data.py
```

รันซ้ำได้ ข้อมูลที่มีอยู่แล้วจะไม่ถูกสร้างซ้ำ

ถ้าอยากให้แดชบอร์ดมีตัวเลขตั้งแต่เปิดจอ ให้รันชุดทดสอบหลายสาขาหนึ่งรอบสั้น ๆ ก่อนเริ่ม (สร้างบิลจริงหลายร้อยใบ และใช้สต๊อกไปส่วนหนึ่ง)

```bash
ERP_BASE=http://localhost:8080/api/v1 DATABASE_URL='postgres://pharmacy:pharmacy@localhost:5432/pharmacy_erp?sslmode=disable' PYTHONPATH=scripts/qa python3 scripts/qa/multi_branch_reconcile.py --sales 10 --threads 1
```

**บัญชีที่ใช้** (รหัสผ่านคือค่า `SEED_ADMIN_PASSWORD` / `SEED_POS_PASSWORD` ของสภาพแวดล้อมนั้น):

| บทบาท | อีเมล | ใช้บนอุปกรณ์ |
| --- | --- | --- |
| สำนักงานใหญ่ | `admin.central@erp.local` | จอใหญ่/โปรเจกเตอร์ |
| POS สาขา MES | `pos.mes@erp.local` | แท็บเล็ต 1 |
| POS หน้ารพ.พหลฯ | `pos.phahol@erp.local` | มือถือ 1 |
| POS คณาเภสัช | `pos.knp@erp.local` | แท็บเล็ต 2 หรือมือถือ 2 |
| เจ้าของระบบ (สำรอง) | `superadmin@erp.local` | ไม่ต้องเปิดต่อหน้าลูกค้า |

**ซ้อม 1 รอบเต็ม** และอัดวิดีโอหน้าจอไว้เป็นแผนสำรองเผื่อเน็ตล่ม

## 3. คำถามที่น่าจะเจอ

| คำถาม | คำตอบ |
| --- | --- |
| เน็ตหลุดขายได้ไหม | ยังไม่มีโหมดออฟไลน์ ต้องต่อเน็ต (ตอบตรง ๆ และบอกว่าอยู่ในแผน) |
| เชื่อม Shopee/Lazada ได้ไหม | ตั้งค่าร้านไว้ได้แล้ว แต่การดึงออเดอร์และตัดสต๊อกจริงอยู่ใน V5 |
| แต้มหมดอายุได้ไหม | ตอนนี้ยังไม่หมดอายุ ตั้งเงื่อนไขอัตรา/มูลค่า/ขั้นต่ำได้แล้ว วันหมดอายุอยู่ในแผนสมาชิก V3 |
| เกินวงเงินแล้วให้ผู้จัดการอนุมัติได้ไหม | ตอนนี้ระบบปฏิเสธอย่างเดียว การอนุมัติวงเงินอยู่ใน V2 |
| รายงานภาษีแยกสาขา | มี ที่เมนูรายงาน (ยอดก่อนภาษี/VAT/ยอดรวมรายสาขา) |

## 4. สิ่งที่ไม่ควรเปิดต่อหน้าลูกค้า

- สต๊อกผี, สรุปสิ้นเดือน และรายงานสรุปสิ้นเดือน (เรื่องภายใน และยังรอการตัดสินใจทางธุรกิจ)
- หน้า `/v2` (pilot ของสำนักงานใหญ่ ยังไม่ผ่านการตรวจรับ)
- รพ.สต. และ อย. (ยังไม่พร้อมใช้งาน)
- บัญชี superadmin

## 5. ถ้ามีอะไรผิดพลาดระหว่าง demo

- **ขายแล้วขึ้น "สต๊อกไม่พอ":** สินค้านั้นหมดใน lot แล้ว ให้เลือกสินค้าอื่น (เป็นการกันขายเกินสต๊อกที่ตั้งใจไว้) จะเล่าเป็นจุดขายก็ได้
- **ใช้แต้มไม่ได้:** แต้มต้องถึงขั้นต่ำ 40 แต้ม ให้ใช้สมาชิกที่มีแต้ม หรือปรับแต้มจากหน้าลูกค้า (สำนักงานใหญ่)
- **ขายเชื่อไม่ได้:** ลูกค้าไม่มีวงเงิน หรือมีบิลเกินกำหนด/เกินวงเงิน ให้ใช้บัญชีขายส่งอีกราย
- **จอค้าง/เน็ตล่ม:** เปิดวิดีโอที่อัดไว้แทน
